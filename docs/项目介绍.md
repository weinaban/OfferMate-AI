# 项目介绍

OfferMate AI 是一个面向 PC 端的智能招聘平台，围绕求职者、招聘者和管理员三类角色构建完整招聘业务流程。项目后端采用 Spring Boot 3.3.x + Java 17，前端采用 Vue3 + Vite + Element Plus，配套 MySQL、Redis、RabbitMQ、Elasticsearch、MinIO、WebSocket、Spring AI 和 LangChain4j 等技术。

项目定位不是单点功能 Demo，而是一个具备真实业务闭环的综合型后端项目：求职者可以维护在线简历、搜索岗位、投递岗位、与招聘者沟通、接收面试邀请；招聘者可以维护企业信息、发布岗位、处理投递、发送面试邀请；管理员可以审核企业和岗位，并查看操作日志。

## 项目目标

- 搭建一个完整的招聘平台业务闭环
- 展示 Java 后端常见中间件的实际落地方式
- 引入 AI 能力，提升求职和招聘场景体验
- 保持代码结构清晰，便于阅读、演示和二次开发

## 用户角色

### 求职者

- 注册登录
- 维护在线简历
- 搜索和查看岗位
- 投递岗位
- 查看投递进度
- 接收面试邀请
- 与招聘者实时聊天
- 使用 AI 简历优化、岗位匹配和模拟面试

### 招聘者

- 维护企业信息
- 发布、修改、下架岗位
- 查看岗位收到的投递
- 修改投递状态
- 发送面试邀请
- 与求职者实时沟通
- 使用 AI 生成岗位描述和面试题

### 管理员

- 用户管理
- 企业审核
- 岗位审核
- 操作日志查询

## 核心模块

| 模块 | 说明 |
| --- | --- |
| 认证与权限 | JWT 登录、拦截器鉴权、角色权限控制 |
| 企业信息 | 招聘者维护企业信息，公开公司主页展示 |
| 岗位管理 | 岗位发布、修改、删除、下架、分页和搜索 |
| 简历管理 | 在线简历创建、修改、删除、设置默认简历 |
| 投递管理 | 求职者投递岗位，招聘者处理投递状态 |
| 面试邀请 | 企业发送邀请，求职者接受或拒绝 |
| 实时聊天 | WebSocket 会话、消息落库、未读统计 |
| 通知中心 | RabbitMQ 异步生成通知 |
| AI 求职助手 | 简历优化、岗位匹配、模拟面试、岗位描述生成 |
| 文件上传 | MinIO 存储头像、Logo、附件简历预留 |
| 管理后台 | 用户、企业、岗位审核和操作日志 |

## 项目特点

1. **业务完整度高**

   项目覆盖招聘平台从注册、企业入驻、岗位发布、求职投递、沟通、面试到后台审核的核心链路，能够比较完整地展示业务建模能力。

2. **中间件使用贴近实际场景**

   Redis 用于缓存、限流、Token 黑名单、防重复投递和未读数；RabbitMQ 用于异步通知和 AI 日志；Elasticsearch 用于岗位搜索；MinIO 用于文件对象存储。

3. **AI 能力与业务结合**

   AI 功能围绕招聘场景设计，包括简历优化、岗位匹配、模拟面试、面试题生成和岗位描述生成，而不是简单的通用问答。

4. **权限边界清晰**

   求职者、招聘者、管理员职责分离，服务层对简历、岗位、投递、聊天、面试邀请等关键资源做归属校验。

5. **适合开源展示**

   项目结构清晰，文档覆盖启动、部署、接口、数据库和架构说明，便于面试官快速理解，也便于学习者二次开发。
