# 部署说明

本文档说明 OfferMate AI 的本地启动和 Docker Compose 部署方式。项目采用前后端分离架构，后端依赖 MySQL、Redis、RabbitMQ、Elasticsearch、MinIO 和 DashScope API。

## 环境要求

本地开发建议：

- JDK 17
- Maven 3.8+
- Node.js 18+
- MySQL 8.x
- Redis 6+
- RabbitMQ 3.x
- Elasticsearch 8.x
- MinIO

Docker 部署建议：

- Docker 24+
- Docker Compose v2+

## 配置说明

后端公开配置文件：

```text
offermate-server/src/main/resources/application.yml
```

本地真实配置文件：

```text
offermate-server/src/main/resources/application-dev.yml
```

示例配置文件：

```text
offermate-server/src/main/resources/application-example.yml
```

`application-dev.yml` 用于本机开发，包含数据库密码、Redis/RabbitMQ 密码、MinIO 密钥、JWT Secret、AI API Key 等敏感信息，已加入 `.gitignore`，不要提交到 GitHub。

`application.yml` 只保留公共配置和 `dev` profile 激活。

核心配置项示例：

```yaml
server:
  port: 8080

spring:
  profiles:
    active: dev
  datasource:
    url: jdbc:mysql://${MYSQL_HOST:localhost}:${MYSQL_PORT:3306}/${MYSQL_DATABASE:offermate}?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false
    username: ${MYSQL_USERNAME:root}
    password: ${MYSQL_PASSWORD:your_password}
    driver-class-name: com.mysql.cj.jdbc.Driver
  data:
    redis:
      host: ${REDIS_HOST:localhost}
      port: ${REDIS_PORT:6379}
      database: ${REDIS_DATABASE:0}
      password: ${REDIS_PASSWORD:your_redis_password}
      timeout: 3000ms
  rabbitmq:
    host: ${RABBITMQ_HOST:localhost}
    port: ${RABBITMQ_PORT:5672}
    username: ${RABBITMQ_USERNAME:your_rabbitmq_username}
    password: ${RABBITMQ_PASSWORD:your_rabbitmq_password}
    virtual-host: ${RABBITMQ_VIRTUAL_HOST:/}

elasticsearch:
  uris: ${ELASTICSEARCH_URIS:http://localhost:9200}

minio:
  endpoint: ${MINIO_ENDPOINT:http://localhost:9000}
  accessKey: ${MINIO_ACCESS_KEY:your_minio_access_key}
  secretKey: ${MINIO_SECRET_KEY:your_minio_secret_key}
  bucket: ${MINIO_BUCKET:offermate}
  publicUrl: ${MINIO_PUBLIC_URL:http://localhost:9000/offermate}

ai:
  dashscope:
    api-key: ${AI_API_KEY:your_ai_api_key}
    chat:
      options:
        model: qwen-plus
        temperature: 0.7

langchain4j:
  qwen:
    api-key: ${AI_API_KEY:your_ai_api_key}
    base-url: https://dashscope.aliyuncs.com/compatible-mode/v1
    model-name: qwen-plus
    temperature: 0.7
    max-tokens: 2000
```

> 注意：不要将真实 API Key、数据库密码、MinIO SecretKey 提交到公开仓库。推荐使用环境变量或部署平台密钥管理能力。

## 本地启动

### 1. 初始化 MySQL

```sql
create database if not exists offermate
  default character set utf8mb4
  collate utf8mb4_unicode_ci;
```

执行 SQL：

```bash
mysql --default-character-set=utf8mb4 -h localhost -P 3306 -u root -p offermate < offermate-server/src/main/resources/sql/offermate.sql
```

### 2. 准备本地配置

复制示例配置为本地开发配置：

```bash
cp offermate-server/src/main/resources/application-example.yml offermate-server/src/main/resources/application-dev.yml
```

然后修改 `application-dev.yml` 中的本地真实配置。

需要重点修改：

- MySQL 用户名和密码
- Redis 密码
- RabbitMQ 用户名和密码
- MinIO accessKey 和 secretKey
- Elasticsearch 地址
- JWT Secret
- DashScope / AI API Key

### 3. 启动依赖服务

本地需要提前启动：

- Redis
- RabbitMQ
- Elasticsearch
- MinIO

MinIO 需要创建 `offermate` bucket，并保证对象可以通过公开 URL 访问。项目上传时会尝试设置 bucket 的 `s3:GetObject` public-read 策略。

### 4. 启动后端

```bash
cd offermate-server
mvn spring-boot:run
```

后端默认地址：

```text
http://localhost:8080
```

### 5. 启动前端

```bash
cd offermate-web
npm install
npm run dev
```

前端默认地址：

```text
http://localhost:5173
```

## Docker Compose 部署

可以使用 Docker Compose 编排以下服务：

- MySQL
- Redis
- RabbitMQ
- Elasticsearch
- MinIO
- offermate-server
- offermate-web + Nginx

示例结构：

```text
docker-compose.yml
nginx/
  default.conf
offermate-server/
offermate-web/
```

示例 `docker-compose.yml` 可按以下思路组织：

```yaml
services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: 1234
      MYSQL_DATABASE: offermate
    ports:
      - "3306:3306"
    command:
      - --character-set-server=utf8mb4
      - --collation-server=utf8mb4_unicode_ci
    volumes:
      - mysql-data:/var/lib/mysql

  redis:
    image: redis:7
    ports:
      - "6379:6379"

  rabbitmq:
    image: rabbitmq:3-management
    environment:
      RABBITMQ_DEFAULT_USER: offermate
      RABBITMQ_DEFAULT_PASS: ${RABBITMQ_PASSWORD:-your_rabbitmq_password}
    ports:
      - "5672:5672"
      - "15672:15672"

  elasticsearch:
    image: docker.elastic.co/elasticsearch/elasticsearch:8.13.4
    environment:
      discovery.type: single-node
      xpack.security.enabled: "false"
      ES_JAVA_OPTS: "-Xms512m -Xmx512m"
    ports:
      - "9200:9200"

  minio:
    image: minio/minio
    command: server /data --console-address ":9001"
    environment:
      MINIO_ROOT_USER: offermate
      MINIO_ROOT_PASSWORD: ${MINIO_SECRET_KEY:-your_minio_secret_key}
    ports:
      - "9000:9000"
      - "9001:9001"
    volumes:
      - minio-data:/data

volumes:
  mysql-data:
  minio-data:
```

启动：

```bash
docker compose up -d
```

生产部署时建议：

1. 使用 `.env` 管理密码和 API Key。
2. 后端镜像构建时跳过测试：

   ```bash
   mvn clean package -DskipTests
   ```

3. 前端构建：

   ```bash
   npm run build
   ```

4. 使用 Nginx 托管前端静态文件，并将 `/api` 和 `/ws` 反向代理到后端。

## Nginx 反向代理示例

```nginx
server {
    listen 80;
    server_name localhost;

    root /usr/share/nginx/html;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://offermate-server:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    location /ws/ {
        proxy_pass http://offermate-server:8080/ws/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}
```

## 常见问题

### 1. 中文乱码

确保：

- 数据库字符集为 `utf8mb4`
- SQL 执行时使用 `--default-character-set=utf8mb4`
- JDBC URL 包含 `characterEncoding=utf8`

### 2. MinIO 图片上传成功但无法访问

需要确认：

- `publicUrl` 指向浏览器可访问地址
- bucket 已创建
- bucket 对对象开启 `s3:GetObject` 公开读取策略

### 3. Elasticsearch 搜索无结果

检查：

- ES 服务是否启动
- `offermate_job` 索引是否存在
- 岗位是否 `status = 1` 且 `audit_status = 1`
- 是否调用过全量同步接口 `/api/jobs/es/sync`

### 4. AI 接口不可用

检查：

- `DASHSCOPE_API_KEY` 是否配置
- 网络是否能访问 DashScope OpenAI 兼容接口
- Redis 限流是否已达到每日上限
