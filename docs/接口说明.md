# 接口说明

后端统一返回结构：

```json
{
  "code": 1,
  "msg": "success",
  "data": {}
}
```

常见状态码：

| code | 说明 |
| --- | --- |
| 1 | 成功 |
| 0 | 业务失败 |
| 401 | 未登录 |
| 403 | 无权限 |
| 500 | 系统异常 |

认证方式：

```text
Authorization: Bearer token
```

WebSocket 地址：

```text
ws://localhost:8080/ws/chat?token=jwt-token
```

发送文本消息示例：

```json
{
  "sessionId": 1,
  "receiverId": 2,
  "content": "你好，我想了解一下岗位",
  "msgType": 1
}
```
