# 数据库设计

数据库名称：`offermate`

字符集建议：

```sql
utf8mb4
```

项目核心数据存储在 MySQL，使用 MyBatis-Plus 进行基础 CRUD 操作。数据库初始化脚本位于：

```text
offermate-server/src/main/resources/sql/offermate.sql
```

## 表结构概览

| 表名 | 说明 |
| --- | --- |
| `sys_user` | 用户表 |
| `company` | 企业信息表 |
| `job_position` | 岗位表 |
| `resume` | 在线简历表 |
| `job_delivery` | 岗位投递表 |
| `chat_session` | 聊天会话表 |
| `chat_message` | 聊天消息表 |
| `interview_invitation` | 面试邀请表 |

| `ai_call_log` | AI 调用日志表 |

| `ai_interview_message` | AI 模拟面试消息表 |

## sys_user

用户基础信息表。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint | 主键 |
| username | varchar(50) | 用户名 |
| password | varchar(100) | BCrypt 加密密码 |
| phone | varchar(20) | 手机号 |
| avatar | varchar(255) | 用户头像 |
| role | tinyint | 1求职者 2招聘者 3管理员 |
| status | tinyint | 1正常 0禁用 |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |

## company

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint | 主键 |
| user_id | bigint | 招聘者用户 ID |
| company_name | varchar(100) | 企业名称 |
| logo | varchar(255) | 企业 Logo |
| industry | varchar(50) | 所属行业 |
| scale | varchar(50) | 公司规模 |
| address | varchar(255) | 企业地址 |
| intro | text | 企业介绍 |
| audit_status | tinyint | 0待审核 1通过 2拒绝 |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |

约束建议：

- `user_id` 唯一索引，保证一个招聘者维护一份企业信息。

## job_delivery

岗位投递记录表。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint | 主键 |
| user_id | bigint | 求职者 ID |
| job_id | bigint | 岗位 ID |
| company_id | bigint | 企业 ID |
| resume_id | bigint | 简历 ID |
| status | tinyint | 投递状态 |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |

投递状态：

| 状态 | 说明 |
| --- | --- |
| 1 | 已投递 |
| 2 | 已查看 |
| 3 | 感兴趣 |
| 4 | 邀面试 |
| 5 | 不合适 |
| 6 | 已录用 |

约束建议：

- `uk_user_job(user_id, job_id)`，防止同一用户重复投递同一岗位。

## AI 模拟面试表

`ai_interview_session` 保存模拟面试会话，`ai_interview_message` 保存多轮上下文消息。

核心关系：

```text
ai_interview_session 1 --- N ai_interview_message
```

## operation_log

操作日志表，用于记录关键接口调用。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint | 主键 |
| user_id | bigint | 用户 ID |
| username | varchar(50) | 用户名 |
| role | tinyint | 角色 |
| module | varchar(50) | 模块 |
| operation | varchar(100) | 操作 |
| method | varchar(255) | 执行方法 |
| request_uri | varchar(255) | 请求路径 |
| request_method | varchar(20) | 请求方式 |
| ip | varchar(50) | IP 地址 |
| params | text | 请求参数 |
| result | text | 返回结果 |
| status | tinyint | 1成功 0失败 |
| error_msg | text | 错误信息 |
| cost_time | bigint | 耗时毫秒 |
| create_time | datetime | 创建时间 |

敏感字段如 password、token、apiKey、secretKey 等在入库前会被过滤。
