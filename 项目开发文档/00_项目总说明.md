# OfferMate AI（精简版项目说明）

## 一、项目名称

OfferMate AI

## 二、项目定位

仿 BOSS 直聘 PC 网页端招聘平台。

目标不是做简单 CRUD，而是完成一个可运行、可部署、可展示的真实招聘网站，并加入 AI 功能提升亮点。

仅做 PC 网页端，不做移动端。

---

## 三、核心角色

### 1. 求职者

- 注册登录
- 浏览岗位
- 搜索岗位
- 创建简历
- 投递岗位
- 在线聊天
- AI 简历优化
- AI 模拟面试

### 2. 招聘者

- 注册登录
- 企业信息维护
- 发布岗位
- 查看投递简历
- 在线聊天
- 邀请面试

### 3. 管理员

- 用户管理
- 企业审核
- 岗位审核
- 数据统计

---

## 四、技术栈

### 后端

- Java 17
- Spring Boot 3.3.5
- Maven
- MyBatis-Plus
- JWT + 拦截器 + ThreadLocal
- WebSocket
- Spring AI

### 数据层

- MySQL
- Redis
- Elasticsearch
- RabbitMQ
- MinIO

### 前端

- Vue3
- JavaScript
- Vite
- Element Plus

### 部署

- Docker Compose
- Nginx
