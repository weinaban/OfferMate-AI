# OfferMate AI｜接口约定（精简版）## 一、通用约定### 1. 接口前缀```text/api
2. 请求格式
Content-Type: application/json
3. Token 传递方式
登录后前端在请求头中携带：
Authorization: Bearer token值
4. 统一返回格式
{  "code": 1,  "msg": "success",  "data": {}}
5. 状态码约定
1 成功0 失败401 未登录403 无权限500 系统异常

二、用户认证接口
功能方法地址是否登录用户注册POST/api/user/register否用户登录POST/api/user/login否用户退出POST/api/user/logout是获取当前用户GET/api/user/current是
登录请求
{  "username": "zhangsan",  "password": "123456"}
登录返回
{  "token": "jwt-token",  "userId": 1,  "username": "zhangsan",  "role": 1}

三、求职者接口
功能方法地址是否登录获取个人资料GET/api/seeker/profile是修改个人资料PUT/api/seeker/profile是上传头像POST/api/seeker/avatar是

四、企业接口
功能方法地址是否登录获取企业信息GET/api/company/info是修改企业信息PUT/api/company/info是上传企业 LogoPOST/api/company/logo是获取企业详情GET/api/company/{id}否

五、岗位接口
功能方法地址是否登录发布岗位POST/api/jobs是修改岗位PUT/api/jobs/{id}是删除岗位DELETE/api/jobs/{id}是下架岗位PUT/api/jobs/{id}/offline是岗位详情GET/api/jobs/{id}否岗位分页列表GET/api/jobs/page否企业岗位列表GET/api/jobs/company是收藏岗位POST/api/jobs/{id}/favorite是取消收藏DELETE/api/jobs/{id}/favorite是
岗位分页查询参数
keywordcitysalaryMinsalaryMaxeducationexperiencepagepageSize

六、简历接口
功能方法地址是否登录创建简历POST/api/resumes是修改简历PUT/api/resumes/{id}是删除简历DELETE/api/resumes/{id}是简历详情GET/api/resumes/{id}是我的简历列表GET/api/resumes/my是设置默认简历PUT/api/resumes/{id}/default是上传附件简历POST/api/resumes/attachment是

七、投递接口
功能方法地址是否登录投递岗位POST/api/deliveries是我的投递记录GET/api/deliveries/my是企业收到的投递GET/api/deliveries/company是修改投递状态PUT/api/deliveries/{id}/status是
投递请求
{  "jobId": 1,  "resumeId": 1}

八、聊天接口
功能方法地址是否登录创建/获取会话POST/api/chats/sessions是我的会话列表GET/api/chats/sessions是查询聊天记录GET/api/chats/sessions/{id}/messages是标记已读PUT/api/chats/sessions/{id}/read是
WebSocket 地址
/ws/chat?token=jwt-token
WebSocket 消息格式
{  "sessionId": 1,  "receiverId": 2,  "content": "你好，我想了解一下这个岗位",  "msgType": 1}

九、通知接口
功能方法地址是否登录通知列表GET/api/notifications是未读数量GET/api/notifications/unread/count是标记已读PUT/api/notifications/{id}/read是全部已读PUT/api/notifications/read/all是

十、AI 接口
功能方法地址是否登录AI 简历优化POST/api/ai/resume/optimize是AI 岗位匹配POST/api/ai/job/match是AI 生成面试题POST/api/ai/interview/questions是AI 面试评分POST/api/ai/interview/score是AI 生成岗位描述POST/api/ai/job/description是
AI 简历优化请求
{  "resumeId": 1,  "jobId": 1}
AI 面试评分请求
{  "question": "请介绍一下你做过的 Spring Boot 项目",  "answer": "我做过一个招聘平台项目..."}

十一、文件上传接口
功能方法地址是否登录通用文件上传POST/api/files/upload是删除文件DELETE/api/files是
上传返回
{  "url": "https://xxx.com/file/avatar.png"}

十二、管理后台接口
功能方法地址是否登录用户列表GET/api/admin/users是禁用用户PUT/api/admin/users/{id}/disable是启用用户PUT/api/admin/users/{id}/enable是企业审核列表GET/api/admin/companies/audit是审核企业PUT/api/admin/companies/{id}/audit是岗位审核列表GET/api/admin/jobs/audit是审核岗位PUT/api/admin/jobs/{id}/audit是AI 调用日志GET/api/admin/ai/logs是
