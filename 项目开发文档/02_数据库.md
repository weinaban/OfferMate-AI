# OfferMate AI｜数据库设计（精简版）

## 一、数据库信息

```text
数据库名：offermate
字符集：utf8mb4
排序规则：utf8mb4_general_ci
存储引擎：InnoDB
二、核心表设计
1. 用户表 sys_user
字段名	类型	说明
id	bigint	主键ID
username	varchar(50)	用户名
password	varchar(100)	登录密码（加密）
phone	varchar(20)	手机号
avatar	varchar(255)	用户头像
role	tinyint	角色：1求职者 2招聘者 3管理员
status	tinyint	状态：1正常 0禁用
create_time	datetime	创建时间
update_time	datetime	更新时间
2. 求职者资料表 seeker_profile
字段名	类型	说明
id	bigint	主键ID
user_id	bigint	用户ID
real_name	varchar(50)	真实姓名
gender	tinyint	性别
age	int	年龄
education	varchar(50)	学历
experience_year	int	工作年限
city	varchar(50)	求职城市
introduction	text	自我介绍
3. 企业表 company
字段名	类型	说明
id	bigint	主键ID
user_id	bigint	招聘者用户ID
company_name	varchar(100)	企业名称
logo	varchar(255)	企业Logo
industry	varchar(50)	所属行业
scale	varchar(50)	公司规模
address	varchar(255)	企业地址
intro	text	企业介绍
audit_status	tinyint	审核状态
4. 岗位表 job_position
字段名	类型	说明
id	bigint	主键ID
company_id	bigint	企业ID
recruiter_id	bigint	招聘者ID
title	varchar(100)	岗位名称
salary_min	int	最低薪资
salary_max	int	最高薪资
city	varchar(50)	工作城市
experience	varchar(50)	经验要求
education	varchar(50)	学历要求
tags	varchar(255)	技能标签
description	text	岗位描述
status	tinyint	岗位状态
view_count	int	浏览量
create_time	datetime	创建时间
5. 简历表 resume
字段名	类型	说明
id	bigint	主键ID
user_id	bigint	用户ID
title	varchar(100)	简历名称
real_name	varchar(50)	姓名
phone	varchar(20)	电话
email	varchar(100)	邮箱
education	varchar(50)	学历
experience_year	int	工作年限
skill	text	技能描述
project_exp	text	项目经历
self_intro	text	自我评价
is_default	tinyint	是否默认简历
6. 投递记录表 job_delivery
字段名	类型	说明
id	bigint	主键ID
user_id	bigint	求职者ID
job_id	bigint	岗位ID
company_id	bigint	企业ID
resume_id	bigint	简历ID
status	tinyint	投递状态
create_time	datetime	投递时间
投递状态
1 已投递
2 已查看
3 感兴趣
4 邀面试
5 不合适
6 已录用
7. 聊天会话表 chat_session
字段名	类型	说明
id	bigint	主键ID
seeker_id	bigint	求职者ID
recruiter_id	bigint	招聘者ID
job_id	bigint	岗位ID
last_message	varchar(255)	最后一条消息
update_time	datetime	更新时间
8. 聊天消息表 chat_message
字段名	类型	说明
id	bigint	主键ID
session_id	bigint	会话ID
sender_id	bigint	发送人ID
receiver_id	bigint	接收人ID
content	text	消息内容
msg_type	tinyint	消息类型
is_read	tinyint	是否已读
create_time	datetime	发送时间
消息类型
1 文本消息
2 图片消息
3 岗位卡片
4 简历卡片
9. 通知表 notification
字段名	类型	说明
id	bigint	主键ID
user_id	bigint	用户ID
title	varchar(100)	通知标题
content	varchar(255)	通知内容
type	tinyint	通知类型
is_read	tinyint	是否已读
create_time	datetime	创建时间
10. AI 调用日志表 ai_call_log
字段名	类型	说明
id	bigint	主键ID
user_id	bigint	用户ID
module	varchar(50)	功能模块
prompt	text	输入内容
result	text	输出内容
create_time	datetime	调用时间
三、第一阶段开发建议优先建表顺序
